# توازن — الماء والصيام المتقطع

تطبيق ويب (PWA) يعمل من الآيفون كأيقونة على الشاشة الرئيسية:
- نظام شرب الماء: قارورة متحركة، هدف يومي، تذكير دوري، سجل وأسبوع وسلسلة أيام.
- الصيام المتقطع ١٦:٨: يبدأ ٨ أو ٩ مساءً، عداد تنازلي، مراحل الصيام، وجبات اليوم والغد من النظام الغني بالبروتين.

## النشر على GitHub Pages
1. ارفع مجلد `tawazun` كما هو إلى المستودع.
2. Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save.
3. الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/tawazun/`
